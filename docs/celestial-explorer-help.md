# 探索清理页星河

清理页右上角提供“探索星河”入口。它不会扫描、删除或修改文件。

## 操作方式

- 点击“探索星河”进入探索模式。
- 在星河上拖动，从不同方向立体旋转天球。经纬网和星体前后大小变化用于提示空间深度。
- 使用鼠标滚轮或 `+` / `-`，围绕视觉中心持续放大或缩小。放得越大，中心附近出现的星体越多。
- 使用“全部星图”“太阳系”“地月系”快速进入常用观察范围；键盘 `0`、`1`、`2` 对应这三个入口。
- 点击带圆环的星体，查看图像效果、类型、距离、实际平均半径和介绍。
- 点击“重置视角”恢复地图中心和默认缩放。
- 点击“退出探索”或按 `Esc` 返回清理界面。

## 尺寸与目录说明

天体的真实半径差异可超过数亿倍，无法在线性比例下同时看清。探索画布使用真实半径的**对数比例**，并在继续放大时同步放大星体本身：大小顺序保持正确，详情卡显示未缩放的 km 数值；没有可靠半径的数据会明确标为未知。

地球、火星和木星的介绍窗使用应用内置 NASA 纹理。其它星体显示“数据化示意”，用于辅助辨识类型和尺度，不代表真实观测照片。

星体信息保存在本机 SQLite 中。应用联网时每七天尝试同步一次 NASA 已确认系外行星及其主星目录；离线或同步失败时继续使用上次成功数据。首次启动且无法联网时，仍可查看内置的太阳系基础目录。
